---
title: "validate"
description: "Run every gate of the Scriipture 9-gate security pipeline against a contract without deploying, with options to skip or isolate individual gates."
---

Runs every gate described in [Security pipeline](/concepts/security-pipeline) and reports issues. Exits non-zero on failure.

## Usage

```bash
npx scriipture validate [options]
```

## Options

| Flag | Description |
| --- | --- |
| `--skip <gate>` | Skip a specific gate. Repeatable. |
| `--only <gate>` | Run only the named gate. |
| `--json` | Emit report as JSON. |

## Example

```bash
npx scriipture validate --skip gas-budget
```
