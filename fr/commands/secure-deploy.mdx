---
title: "secure-deploy"
description: "Déployez avec une piste d'audit complète : attestation de bytecode, preuves d'invariants et métadonnées signées."
---

Exécute [`deploy`](/commands/deploy) et produit en plus un bundle d'audit : hachage du bytecode, rapport `slither`, preuves d'invariants et un JSON de métadonnées signé et épinglé sur IPFS.

## Utilisation

```bash
npx scriipture secure-deploy <contract> --chain <chain> [options]
```

## Options

| Option | Description |
| --- | --- |
| `--browser` | Signer via le portefeuille de navigateur. |
| `--ipfs-gateway <url>` | Épingle les métadonnées sur une passerelle IPFS personnalisée. |
| `--sign-with <key>` | Signe le bundle de métadonnées avec une clé spécifique. |

<Note>
  Utilisez `secure-deploy` en production. Utilisez [`deploy`](/commands/deploy) pour les testnets et l'itération.
</Note>
