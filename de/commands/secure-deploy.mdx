---
title: "secure-deploy"
description: "Deploy mit vollständigem Audit-Trail: Bytecode-Attestierung, Invariantenbeweise und signierte Metadaten."
---

Führt [`deploy`](/commands/deploy) aus und erzeugt zusätzlich ein Audit-Bundle: Bytecode-Hash, `slither`-Report, Invariantenbeweise sowie ein signiertes Metadaten-JSON, das auf IPFS gepinnt wird.

## Verwendung

```bash
npx scriipture secure-deploy <contract> --chain <chain> [options]
```

## Optionen

| Flag | Beschreibung |
| --- | --- |
| `--browser` | Über Browser-Wallet signieren. |
| `--ipfs-gateway <url>` | Metadaten auf einem eigenen IPFS-Gateway pinnen. |
| `--sign-with <key>` | Das Metadaten-Bundle mit einem bestimmten Schlüssel signieren. |

<Note>
  Verwende `secure-deploy` für die Produktion. Nutze [`deploy`](/commands/deploy) für Testnets und Iteration.
</Note>
