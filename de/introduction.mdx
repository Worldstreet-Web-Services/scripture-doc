Mit Scriipture kannst du Smart Contracts in **reinem TypeScript** schreiben – derselben Sprache, die du bereits für deine APIs und dein Frontend verwendest. Keine neue Sprache. Kein neues Tooling. Es reicht `npm install`, eine Klasse schreiben und deployen.

```bash
npm install scriipture
```

## Für TypeScript-Entwickler:innen konzipiert

Wenn du Node.js kennst, kennst du bereits 90 % von Scriipture. Ein Smart Contract ist einfach eine Klasse. Methoden werden zu Funktionen, die jeder aufrufen kann. Klassenfelder werden zum Storage. Das ist das gesamte Modell.

```ts Counter.ts
import { storage } from "scriipture";

export class Counter {
  @storage count: bigint = 0n;

  increment(): void {
    this.count += 1n;
  }
}
```

Scriipture kümmert sich um alles Blockchain-Spezifische für dich: Es generiert den Low-Level-Contract-Code, prüft ihn auf verbreitete Fehler und deployt ihn über deine Browser-Wallet. Du musst TypeScript nie verlassen.

## Neu bei Smart Contracts?

Kein Problem. Hier die 30-Sekunden-Version:

- Ein **Smart Contract** ist ein Programm, das auf einer Blockchain lebt. Nach dem Deploy kann jeder seine Funktionen über das Internet aufrufen.
- Eine **Blockchain** (Ethereum, Base, Konstellation) ist eine gemeinsame Datenbank, auf die sich viele Computer einigen. Einen Contract zu deployen ist wie ein `POST` von Code an diese Datenbank.
- Eine **Wallet** (wie MetaMask) ist deine Identität. Du nutzt sie, um Deploys und Transaktionen zu signieren – so, wie du dich mit einem Google-Konto anmeldest.

Das war's. Du kannst jetzt den Rest der Dokumentation lesen.
