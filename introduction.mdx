Scriipture lets you write smart contracts in **plain TypeScript**, the same language you already use for your APIs and frontend. No new language to learn. No new tooling. It's just `npm install`, write a class, and deploy.

```bash
npm install scriipture
```

## For TypeScript developers, by design

If you know Node.js, you already know 90% of Scriipture. A smart contract is just a class. Methods become functions anyone can call. Class fields become storage. That's the whole model.

```ts Counter.ts
import { storage } from "scriipture";

export class Counter {
  @storage count: bigint = 0n;

  increment(): void {
    this.count += 1n;
  }
}
```

Scriipture handles everything blockchain-specific for you: it generates the low-level contract code, checks it for common bugs, and deploys it via your browser wallet. You never have to leave TypeScript.

## New to smart contracts?

That's fine. Here's the 30-second version:

- A **smart contract** is a program that lives on a blockchain. Once deployed, anyone can call its functions over the internet.
- A **blockchain** (Ethereum, Base, Konstellation) is a shared database that many computers agree on. Deploying a contract is like `POST`-ing code to that database.
- A **wallet** (like MetaMask) is your identity. You use it to sign deploys and transactions, the same way you'd use a Google account to sign in.
